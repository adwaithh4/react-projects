# React Projects

A collection of React and full-stack web development projects built while learning and practicing modern web development concepts.

## Projects

### 1. Tic-Tac-Toe 🎮

A classic Tic-Tac-Toe game built with React, demonstrating component-based UI development, state management, event handling, and conditional rendering.

### 2. Investment Calculator 💰

A React-based investment calculator that calculates projected investment results based on initial investment, annual contribution, expected return, and investment duration.

### 3. Authentication-Based Events Page 🔐

An events application built with React and authentication, featuring user login, protected content, event browsing, and authenticated access to application features.

### 4. Guessing Game 🎯

An interactive number guessing game that challenges users to guess timer while providing feedback based on each attempt.

### 5. Foodies — Single Page Application 🍔

A food-focused single-page application built with React, featuring a dynamic food menu, reusable components, and an interactive user interface.

### 6. Validation Page ✅

A form validation project demonstrating controlled inputs, validation rules, error handling, and user feedback using React.

### 7. Place Picker 📍

A location-based React application that allows users to discover and select places based on their location, demonstrating browser geolocation, dynamic data, and interactive UI components.

### 8. Todo 📝

A Todo application built with React for creating, managing, and tracking tasks while demonstrating state management, event handling, and dynamic rendering.

---

## Purpose

This repository contains projects developed as part of my journey in learning and practicing React and full-stack web development.

Each project focuses on different concepts, ranging from React fundamentals and state management to authentication, APIs, form validation, and location-based features.
